Needs a human

These cannot be verified from an automated session: macOS only delivers input to an AX-trusted process, and Screen Recording permission is per build.

1. Annotator click-through 10 min

Press ⌘⇧4 → Capture a region and annotate, or run /shot and pick an annotate row.

  • Click a mark: dashed white outline appears, nothing new is drawn.
  • Drag it: it moves; press delete: it goes; ⌘Z brings it back.
  • Text tool: click, type, press return — text appears where you clicked.
  • ⌘+ / ⌘- / ⌘0 zoom; the canvas scrolls while zoomed.
  • ⌘⇧S writes a separate file; ⌘S overwrites the capture.
  • Resize the window to its minimum: the toolbar keeps every button readable.

2. Shortcut conflicts 2 min

⌘⇧3 and ⌘⇧4 are Apple's screenshot keys and Shottr may hold them too. Press each one: if the wrong app answers, rebind in Settings → Shortcuts. Palette reports a taken key in the panel and in the log instead of failing silently.

3. Permission prompts 2 min

Every release is ad-hoc signed, so macOS treats it as a new app.

  • First screenshot: grant Screen Recording once.
  • First paste: grant Accessibility once.
  • Nothing is granted silently; a refusal shows the exact Settings path.

4. First-run setup optional

Onboarding only appears when Palette creates config.toml, so upgrades skip it by design. To see it again:

brew uninstall --cask --zap palette && brew install --cask Myleshen/tap/palette

This also clears the two privacy grants, so the prompts in step 3 return.

Known constraints

  • Signing. Ad-hoc, so Screen Recording and Accessibility grants reset after every release. Accepted.
  • Uninstall. brew uninstall --cask --zap palette removes data; the privacy grants need tccutil reset Accessibility dev.myleshen.palette and tccutil reset ScreenCapture dev.myleshen.palette. Casks cannot run commands on uninstall.
  • Layout guard. make layout-check is local, not in CI, and the Advanced pane prints the version — re-record with Scripts/layout-check.sh --record after every version bump.
  • Homebrew trust. A fresh machine may need brew trust --tap Myleshen/tap before the cask loads.

Done in 2.6.0

  • Pointer tool as the default: select, move, delete; drawing tools no longer grab marks.
  • Text size stepper and in-place text entry.
  • Dock icon no longer lingers: the accessory policy follows editor and player windows only.
  • Setup window has a real title bar instead of a blank strip.
  • [capture] gallery filters /shots to Palette's own captures.
  • make layout-check with reference snapshots; catches layout drift (14.30% when the old clipping bug was reintroduced).
  • Docs back to Markdown with uninstall, trust and layout-check sections.

Decisions

  • No Apple developer account. Ad-hoc signing accepted; the permission re-grant per update is the cost.
  • Semver. Additive tools, defaults and config keys are minor bumps (2.6.0), fixes are patches.
  • Docs. Markdown for anything GitHub renders (README files and the docs linked from them); HTML for plans, trackers and reports — this file.

Nothing above is blocking. When the four human checks pass, this page has no open work left.
